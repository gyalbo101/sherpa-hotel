# Sherpa Hotel, Thulo Bharkhu

Website for Sherpa Hotel, a family-run Sherpa teahouse on the Pasang Lhamu Highway at Thulo Bharkhu, Rasuwa, Nepal. The trailhead for Gosainkunda via Chandanbari (Sing Gompa), and for Brabal, Thulo Syabru and Langtang Valley.

Static single page (`index.html`), hosted on GitHub Pages.
